# AZiL Arazi Atlası — Windows Başlatıcı

Bu depo, [AZiL Arazi Atlası web uygulamasını](https://sbncifci.tr.gg/Arazi-Atlasi.htm) Windows'ta açan küçük bir başlatıcı ve EXE oluşturma hazırlama paketini barındırır.

## İndir

- [Başlatıcı ZIP](downloads/AZiL_Arazi_Atlasi_Baslatici.zip): Python başlatıcı (`atlas_baslat.py`) ve `BASLAT.bat`.
- [EXE hazırlama ZIP](downloads/AZiL_Arazi_Atlasi_Hazirlama.zip): Başlatıcıya ek olarak `EXE_OLUSTUR.bat` ve açıklamalar.

**Önemli:** Bu paket, tam çevrimdışı CBS/masaüstü Arazi Atlası değildir. Mevcut web uygulamasını tarayıcıda açan bir başlatıcıdır. Python 3.10+ gerektirir; EXE derleme işlemi PyInstaller kullanır. Windows üzerinde çalışma testi henüz doğrulanmadı.
